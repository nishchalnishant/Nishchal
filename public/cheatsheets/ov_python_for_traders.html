    Why Python for finance#

    • Pure Python is slow at big loops: it handles one value per step.
    • Libraries are fast because a readable Python layer sits on a compiled core: NumPy and pandas (C), TA-Lib (C), TensorFlow (C++), OpenAlgo and OpenGreeks (Rust). "Python is the steering wheel; C and Rust are the engine."
    • Summing the squares of 5 million numbers: a plain loop took about 468 ms, NumPy about 15 ms, roughly 30× faster for the identical answer.
    • pandas was created in 2008 at a hedge fund (AQR); its name comes from "panel data". Banks, quant funds and Indian prop desks run research and automation in Python.
    Check yourself 2 questions

    1. Why is pure Python slow at big loops?

      Show answer

      It handles one value per step; vectorised libraries hand the loop to compiled code.

    2. What languages power NumPy and pandas underneath?

      Show answer

      C.

    Takeaway Python is the steering wheel and C or Rust the engine: libraries are fast because a readable layer sits on a compiled core.

    Decisions: if, elif, else#

    def signal(price, sma, rsi):
    if price <= 0:                      # guard clause first
        return "BAD DATA"
    if price > sma and rsi < 70:
        return "BUY"
    elif price < sma:
        return "SELL"
    else:
        return "HOLD"

signal(1313.60, 1305.00, 45)   # BUY
signal(1313.60, 1305.00, 75)   # HOLD: overbought, still above SMA
    • Only the first true branch runs, so order matters.
    • Indentation (4 spaces) is syntax: it defines the block.
    • Test bad cases first and return early instead of nesting deeply.

      Show answer

    Takeaway Put guard clauses first; only the first true branch runs, so order conditions carefully.

    Functions#

    def pct_change(old, new):
    """Percentage change from old to new."""
    return (new - old) / old * 100

def brokerage(turnover, rate=0.0003, cap=20.0):
    """0.03% of turnover, capped at ₹20 per order."""
    return min(turnover * rate, cap)

def trade_summary(buy, sell, qty):
    profit = (sell - buy) * qty
    return profit, pct_change(buy, sell)   # a tuple

brokerage(10000)              # 3.0
brokerage(500000)             # 20.0 (150 capped)
p, move = trade_summary(1300, 1313.60, 50)  # 680.0, 1.05

    One function means one place to fix a bug. A function without return gives back None; defaults apply only when the argument is left out.

      Brokerage at a rate, capped at ₹20 per order.

    2. How does a function return two values?

      Show answer

      As a tuple, e.g. return profit, pct.

    Takeaway Functions name a job, take arguments with sensible defaults, document themselves and can return several values.

    The unstuck ladder#

    1. Read the error: the last line names the problem.
    2. Ask Python: type(x) (what is it?), dir(x) (what can it do?), help(x) (how?).
    3. Search the exact message, in quotes.
    4. Shrink it to the smallest snippet that still fails; that often reveals the bug.
    5. Ask clearly: code, output, and what you tried.

    Experts look things up constantly. Be wary of pasting code you don't understand, from anywhere.

    Check yourself 2 questions

    1. Which line of a traceback names the problem?

    NumPy: vectorised maths#

    import numpy as np
c = np.array([291.58, 295.63, 291.13, 296.42, 299.24])
c - c[0]                         # rebase to day 1
c / c[0] * 100                   # % of start
ret = np.diff(c) / c[:-1] * 100  # daily returns, no loop
(c > c.mean()).sum()             # count days above average
np.where(ret > 0, "up", "down")
rng = np.random.default_rng(42); rng.normal(0, 1, 5)
    • Arrays hold one numeric type and one shape; .shape, .ndim, .reshape, .T.
    • axis=0 runs down columns, axis=1 across rows; scalars and smaller arrays broadcast.
    • * is element-wise, not matrix multiplication. NumPy's std defaults to population (ddof 0), pandas to sample (ddof 1).

    Prices → returns → signal → scorecard#

    close = df["Close"]
ret = close.pct_change()
growth = (1 + ret).cumprod()                       # growth of ₹1
total = (growth.iloc[-1] - 1) * 100
fast, slow = close.rolling(10).mean(), close.rolling(30).mean()
position = (fast > slow).astype(int)  # 1 = in the market
trades = position.diff()  # +1 buy, −1 sell
strat = position.shift(1) * ret  # act on the NEXT bar
win_rate = (ret > 0).sum() / ret.notna().sum()
drawdown = (growth / growth.cummax() - 1) * 100
max_dd = drawdown.min()
    • In the course's six-month RELIANCE sample: buy-and-hold −15.31%, best day +3.36%, worst −4.60%, 44.7% up days, max drawdown −20.58%. Buy-and-hold can lose.
    • The course's scorecard measures the stock's own returns; to judge a strategy, score strat. The shift(1) is our addition: a signal from today's close can only be acted on tomorrow, otherwise the test peeks into the future.
    • Six months, no costs and one stock prove nothing: distrust attractive results. The Algo Trading and Quant sheets go further.
